Your collection, prepared once,
portable everywhere.

Talea is a free, open-source DJ app. Cues, loops and beat grids live next to your music — on any drive — and move freely between rekordbox, Engine DJ, Serato and Talea itself.

Download for macOS View source

GPL-2.0 · macOS (Apple silicon) · Windows & Linux planned

Built like an instrument, not a viewer

An audio engine written from scratch in Rust with a strict real-time discipline: no locks, no allocation, no surprises in the audio path.

Portable libraries

Your prep data lives in a sidecar folder next to the music, per drive. Plug the same USB into any machine running Talea and everything is there — cues, loops, grids, ratings.

Real import bridges

Reads rekordbox USB exports (PDB/ANLZ), Engine DJ drives and Serato libraries — validated against real hardware exports, not just spec documents.

Browse USBs in place

Plug in a rekordbox or Engine stick and play straight from it — playlists, cues and beat grids included — without importing anything or writing a single byte to the drive.

Performance engine

Key lock, beat sync, quantize, isolator EQ with true kills, effects, hot cues and saved loops — with engine-owned state, so what you hear is always what you see.

MIDI controllers

Declarative JSON mappings with soft takeover and LED feedback. DDJ-400 ships built in; community mappings install with one click.

Export back out

Leaving is a feature: export your library to Engine DJ, Serato or rekordbox formats. Your preparation work is yours, in every direction.
